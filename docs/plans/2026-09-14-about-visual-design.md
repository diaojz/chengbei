# About 视觉升级设计

## 方向

采用“未来实验室 × 独立编辑部”。画面使用真实玻璃、磨砂金属、矿石、细轨迹和轻微胶片颗粒，不使用霓虹城市、机器人、芯片、UI 面板等常见 AI 视觉符号。

## 明暗主题

- 亮色：暖象牙白、浅灰石材、石墨灰金属，以少量电光蓝作视觉锚点。
- 暗色：深墨黑、冷白金属、黑色岩石，保持同一比例的电光蓝。
- 两套素材共用构图与物体关系，不采用 CSS 简单反色；手动切换站点主题时同步替换。

## 页面落点

1. About 首屏使用 21:9 宽幅背景，视觉重心在右侧，左侧保留标题负空间。
2. 正文宣言之后加入 1:1 玻璃立方体静物，作为“想法、代码、验证汇合”的视觉隐喻。
3. 手机端保留首屏画面的空间感，小图改单列，不让图片挤压正文。

## 性能与可访问性

- 生成素材转为 WebP，四张合计控制在 350 KB 内。
- 背景图为装饰性信息；正文中的小图使用空 `alt`，由相邻文字传达含义，避免屏幕阅读器重复朗读。
- 图片声明原始宽高并延迟加载，减少布局跳动。

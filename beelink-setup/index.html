Set up your Beelink Mini S安装你的 Beelink Mini S

Follow the 8 steps in order. No experience needed. Tick “Done” after each step — your progress is saved.按顺序做 8 步即可，零基础可用。每完成一步点“Done”，进度会自动保存。

⏱ 45–60 min🧰 No tech skills needed🔒 No router settings

We will turn the little computer into an always-on Linux box (Ubuntu Server 24.04 LTS) that sits next to your router. After that, we connect to it remotely. You never need to open router ports or share personal passwords.我们要把这台小主机装成一台常开的 Linux 小主机（Ubuntu Server 24.04 LTS），放在路由器旁边，之后由我们远程连接。你不需要改路由器端口，也不用提供任何个人密码。

Heads-up: the Beelink comes with Windows. This guide erases Windows and replaces it. That is expected — the machine is new.提醒：Beelink 自带 Windows，本教程会清除 Windows 并替换，这是预期的，机器是新的。

0What you need先准备这些

Beelink Mini S + power adapterBeelink 主机 + 电源适配器
Ethernet cable to your router网线（接路由器）
USB stick, 8 GB or bigger (will be erased)U 盘 8GB 以上（会被清空）
Monitor/TV with HDMI + HDMI cable带 HDMI 的显示器 + HDMI 线
USB keyboard (setup only)USB 键盘（仅安装时用）
A second computer (Windows or Mac) to prepare the USB另一台电脑（Win/Mac）用来做启动 U 盘

1Download Ubuntu Server下载 Ubuntu Server

  1. On your other computer, open ubuntu.com/download/server在另一台电脑上打开 ubuntu.com/download/server
  2. Download Ubuntu Server 24.04.5 LTS (.iso, about 2–3 GB). Not the newest 26.04 at the top — scroll down to Previous releases and click Download 24.04.5 LTS. Wait until it finishes.下载 Ubuntu Server 24.04.5 LTS（.iso 文件，约 2–3 GB）。不要下页面最上方最新的 26.04，向下滚动到 Previous releases，点 Download 24.04.5 LTS，等它下载完。
Illustration — the real page may look slightly different.示意图，真实页面可能略有不同。

2Make the bootable USB stick制作启动 U 盘

  1. Install balenaEtcher (free): etcher.balena.io. (On Windows, Rufus also works.)安装免费工具 balenaEtcher：etcher.balena.io（Windows 也可用 Rufus）。
  2. Plug the USB stick into this computer and open Etcher.把 U 盘插到这台电脑，打开 Etcher。
  3. ① Flash from file → pick the Ubuntu .iso · ② Select target → pick your USB stick · ③ Flash!① Flash from file 选 Ubuntu 的 .iso · ② Select target 选你的 U 盘 · ③ 点 Flash!
Etcher has just 3 buttons. Wait until it says “Flash Complete”.Etcher 只有 3 个按钮，等它显示 “Flash Complete”。
Check twice: the “target” must be your USB stick, not another drive. Everything on the stick will be erased.再确认一遍：目标必须是 U 盘，不是别的硬盘；U 盘里的内容会被清空。

3Connect everything & boot from the USB接线并从 U 盘启动

  1. Plug into the Beelink: Ethernet cable → router, HDMI → monitor, keyboard, and the USB stick.给 Beelink 接上：网线 → 路由器、HDMI → 显示器、键盘和启动 U 盘。
  2. Plug in the power. The Beelink turns on.最后接电源，主机会开机。
  3. Right away, tap F7 again and again (about once per second) until a boot menu appears.立刻连续点按 F7（约每秒一次），直到出现启动菜单。
  4. Choose the USB entry — best the one starting with UEFI: — and press Enter.选择 U 盘那一项（最好是以 UEFI: 开头的），按 Enter。
Illustration. Port positions on your Beelink may differ — match them by the little icons next to each port.示意图，实际接口位置可能不同，请按接口旁边的小图标对号入座。
The two keys you will use.会用到的两个按键。
Not working?
• No USB in the menu: unplug the stick, wait 5 s, plug it back, restart and tap F7 again.
• Black screen after choosing it: restart; when the Ubuntu menu shows press e, add nomodeset at the end of the line starting with linux, then press F10.
• Still won’t start: restart, tap Del to enter BIOS, turn Secure Boot off, save & exit, retry.
• Stuck? Take a photo and send it to us.不成功？
• 菜单里没有 U 盘：拔掉 U 盘等 5 秒再插回，重启后再按 F7。
• 选了之后黑屏：重启，出现 Ubuntu 菜单时按 e，在以 linux 开头那行末尾加上 nomodeset，按 F10。
• 仍然启动不了：重启按 Del 进 BIOS，把 Secure Boot 关掉，保存退出再试。
• 卡住了就拍照发给我们。

4Install Ubuntu Server安装 Ubuntu Server

The installer is a text screen. Use ↑ ↓ to move, Enter to choose, Space to tick a box. Go screen by screen:安装界面是文字界面：↑ ↓ 移动，Enter 确认，Space 勾选。逐屏操作：

  1. Language English → keyboard: your layout → Done.语言选 English → 键盘选你自己的布局 → Done。
  2. Type of install: Ubuntu Server (NOT “minimized”).安装类型选 Ubuntu Server（不要选 minimized）。
  3. Network: you should see a wired connection with an IP number like 192.168.x.x. Leave defaults → Done.网络：应看到有线连接和类似 192.168.x.x 的 IP，保持默认 → Done。
  4. Proxy and mirror: leave defaults → Done.代理和镜像源：保持默认 → Done。
  5. Storage: choose Use an entire disk and select the Beelink’s internal drive (not the USB stick). Accept the rest → Done → Continue. This erases Windows.存储：选 Use an entire disk，目标选 Beelink 的内置硬盘（不是 U 盘），其余默认 → Done → Continue。这一步会清除 Windows。
Example. Pick the big internal drive, not the small USB stick.示例：选容量大的内置硬盘，不要选小的 U 盘。
  1. Profile: your name, a server name (e.g. homebox), a username and a password. Write them down and keep them safe.账户：填姓名、主机名（如 homebox）、用户名和密码。请抄下来妥善保管。
  2. Ubuntu Pro: choose Skip.Ubuntu Pro：选 Skip 跳过。
  3. SSH setup: press Space to tick “Install OpenSSH server” so it shows [X]. This is very important — it lets us help you remotely.SSH 设置：按 Space 勾选 “Install OpenSSH server”，使其显示 [X]。这一步很重要，我们要靠它远程协助。
  4. Featured snaps: tick nothing → Done.Featured snaps：什么都不勾 → Done。
  5. Wait for the installation (5–15 min). When it says Install complete, choose Reboot Now. When asked, unplug the USB stick and press Enter.等待安装（5–15 分钟）。出现 Install complete 后选 Reboot Now；提示时拔掉 U 盘并按 Enter。
The OpenSSH box must be ticked.OpenSSH 这一项必须打勾。
If a screen looks different from this list, stop and send us a photo — do not guess.如果某一屏和上面不一样，先停下来拍照发给我们，不要猜。

5Auto-restart after a power cut设置断电后自动开机

  1. Restart the Beelink and tap Del again and again to enter the BIOS (a blue/grey settings screen).重启 Beelink，连续点按 Del 进入 BIOS（蓝/灰色设置界面）。
  2. Look for a power option — on Beelink usually Chipset → PCH-IO Configuration → State After G3 (or “Restore on AC Power Loss”). Set it to S0 State / Power On.找电源选项，Beelink 通常在 Chipset → PCH-IO Configuration → State After G3（或 “Restore on AC Power Loss”），设为 S0 State / Power On。
  3. Check the boot order: the internal drive (Ubuntu) should be first.确认启动顺序：内置硬盘（Ubuntu）排第一。
  4. Save & exit (F4 or the “Save & Exit” tab).保存并退出（F4 或 “Save & Exit” 页）。
Menu names differ by model. If you can’t find it, photograph the BIOS screens and send them to us.不同机型菜单名不同，找不到就把 BIOS 画面拍照发给我们。

6Log in & check the network登录并检查网络

  1. After the restart you see a black screen with login:. Type your username, press Enter, then your password (nothing shows while typing — that’s normal), Enter.重启后出现黑屏和 login:。输入用户名回车，再输入密码（输入时屏幕不显示，这是正常的），回车。
  2. Type these two commands (one at a time, Enter after each):依次输入这两条命令（每条后回车）：
ip -br a
ping -c 3 1.1.1.1
What a good result looks like (numbers will differ).正常结果长这样（数字会不同）。
✔ Good: an address like 192.168.x.x and 0% packet loss.✔ 正常：有 192.168.x.x 这样的地址，且 0% packet loss。
No address or packet loss? Check the Ethernet cable is firmly in both the Beelink and the router, then retry. Still bad → send us a photo.没有地址或丢包？检查网线两头都插紧，再试一次。仍不行就拍照发给我们。

7Send us two things发给我们两样东西

  1. A photo of the screen showing the result of the two commands in Step 6.第 6 步两条命令结果的屏幕照片。
  2. The model name on the sticker under the Beelink (e.g. “Mini S12 Pro” or “Mini S13”).主机底部标签上的型号（如 “Mini S12 Pro” / “Mini S13”）。
Never send your password. We don’t need it now. Later we will send you a private one-time setup link and a small installer — treat that link like a password: don’t post it in groups or public places.不要发密码。现在不需要。之后我们会给你一个私密的一次性设置链接和一个小安装包；这个链接等同于密码，不要发到群里或公开场合。

8Leave it running保持运行

When we confirm everything works:我们确认一切正常后：

  • Remove the monitor, keyboard and USB stick.拔掉显示器、键盘和 U 盘。
  • Keep power and Ethernet connected 24/7, in a spot with some airflow (not covered).电源和网线 24 小时保持连接，放在通风处，不要盖住。
  • Don’t turn it off or unplug the network unless we ask. Tell us first if you need to move it.没有我们通知不要关机或拔网线，需要挪位置请先告诉我们。

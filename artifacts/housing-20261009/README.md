## 数据口径：不得把情景估算写成实际账单

报价与测算截至 **2026-09-27**，不是文章发布日或文档更新日的最新估价。

| 类型 | 信息与限制 |
|---|---|
| 作者提供 | 2019 年 1 月购房，地点房山，购房价 410 万，首付 30%，贷款期限 20 年，截至上述日期报价 270 万；未公开或独立核验合同与银行流水 |
| 根据价格计算 | 若以 270 万成交，价差为 140 万，跌幅约 34.15%；报价不是已成交价格 |
| 贷款模型 | 公积金 100 万、商贷 187 万，年利率分别为 3.25%、5.88%，20 年等额本息，已还 93 期，无提前还款，全程利率不变 |
| 尚未确认 | 实际贷款拆分、首期扣款月份、还款方式、历次调息与提前还款；100 万不是确认过的北京最高额度，5.88% 不是确认过的历史利率上限 |
| 租金模型 | 平均月租 3,000—6,000 元，仅为敏感性比较，未调查当地历史租赁成交；按自住且无出租收入比较 |
| 尚未计入 | 买卖税费、中介费、装修、差异化持有成本、出租收入、通胀和资金投资收益 |

模型核心结果（万元，另有说明除外）：

| 指标 | 数值 |
|---|---:|
| 月供（元） | 18,940.08 |
| 累计月供 | 176.14 |
| 已还本金 | 79.51 |
| 已付利息 | 96.63 |
| 剩余本金 | 207.49 |
| 首付加累计月供 | 299.14 |
| 270 万卖出、结清本金后剩余，未扣费用 | 62.51 |
| 房价损失加模型利息 | 236.63 |
| 假设月租 4,000 元，93 个月租金 | 37.20 |
| 两者净支出差额 | 199.43 |

复核恒等式：`首付 + 累计偿还本息 − (卖价 − 剩余本金) = 买入价 − 卖价 + 累计利息`。不要再次叠加首付或已还本金。

## 复算与更新

在仓库根目录运行：

```bash
python3 artifacts/housing-20261009/reproduce.py
python3 artifacts/housing-20261009/render_charts.py
node scripts/content-manifest.mjs --write
npm run check
npm run build
git diff --check
```

复算仅依赖 Python 标准库；绘图另需 Pillow，以及 `~/Library/Fonts/SourceHanSansCN-Heavy.otf`、`~/Library/Fonts/Alibaba-PuHuiTi-Medium.otf`。标题使用思源黑体 Heavy，正文使用阿里巴巴普惠体 Medium；图片中的字是程序排版，不是模型生字。

**修改参数时要同时更新正文、索引摘要（如涉及数字）、两种语言的图表文字及 alt 文本。** 绘图脚本的部分展示标签为定稿文案，不能仅重跑复算脚本就认为所有图中文字会自动更新。图表必须重新逐张验图，检查数字、字形、截断和比例。

拿到实际贷款记录后，优先使用银行累计利息与剩余本金，或按每次调息时点重建还款表；不得直接把当前利率套回整个持有期。更新正文时保留原发布日期，并另记修订日期。
